⚙️ 10 Систем и Ключевые Механики
⚡ Гейт раскадровки (Zero-Token-Waste) Семантика
До написания кода Claude обязан выдать подробную посекундную раскадровку (00:00–00:03 интро, 00:03–00:07 оффер и т.д.). Ошибки сценария отсекаются на этапе текста без затрат на тяжелый рендеринг.
⚡ Референсный инжиниринг Контроль ОТК
Вместо абстрактной команды «сделай красиво», пользователь загружает видео-референс. Claude анализирует композицию, тайминг смены кадров и кривые анимации (easings), перенося паттерн в код.
⚡ Финансовый предохранитель (Budget Gatekeeper) Анти-дубли
Скилл жестко блокирует вызовы платных API до тех пор, пока Claude не посчитает точную смету и не предложит варианты экономии (в ролике цена сбита с 1 320 до 350 руб).
⚡ Дисковый клининг Индексация
Видеорендеринг в высоком разрешении быстро засоряет диск гигабайтами временных скриншотов и буферов. Скилл принудительно запрашивает команду на удаление кэша сразу после финализации MP4.

# Регламент Моушн-Дизайнера Claude
1. Проверь наличие свободного места на диске (>5 ГБ) и установку ffmpeg (`ffmpeg -version`).
2. Запроси у пользователя:
   - Цель ролика и целевой формат (9:16 Shorts/Reels или 16:9 дашборд/витрина).
   - Бренд-ассеты (логотип SVG, цвета HEX, скриншоты продукта).
   - Видеореференс (ссылка или файл) для копирования темпа анимации.
3. Составь посекундную раскадровку сцен с указанием длительности кадров.
4. Дождись явного согласования раскадровки от пользователя перед генерацией кода!
5. Если требуются платные генерации (озвучка, музыка, видео людей):
   - Рассчитай смету.
   - Предложи бесплатную $0 альтернативу (Edge-TTS для голоса, royalty-free аудио).
   - Получи подтверждение бюджета.
6. Напиши Remotion-композицию и выполни локальный рендер:
   `npx remotion render src/index.ts <CompositionName> out/video.mp4`
7. После успешного рендера удали временные кэш-файлы из папки `out/cache`.

Генерация дикторской озвучки студийного качества на русском языке через Edge Neural TTS без API-ключей.
python 
#!/usr/bin/env python3
import asyncio
import edge_tts
from pathlib import Path

VOICE_RU = "ru-RU-DmitryNeural" # Глубокий мужской голос диктора
OUTPUT_AUDIO = Path("out/voiceover.mp3")

async def generate_speech(text: str, output_file: Path):
    output_file.parent.mkdir(parents=True, exist_ok=True)
    communicate = edge_tts.Communicate(text, VOICE_RU, rate="+0%", pitch="+0Hz")
    await communicate.save(str(output_file))
    print(f"✅ Озвучка готова ($0 затрат): {output_file}")

if __name__ == "__main__":
    script_text = "Металл, точность, звук. Gemstudio представляет новый контур технологий."
    asyncio.run(generate_speech(script_text, OUTPUT_AUDIO))

Кинетическая типографика и плавное появление карточек продукта с физикой spring-анимации.
tsx 
import { AbsoluteFill, interpolate, spring, useCurrentFrame, useVideoConfig } from "remotion";
import React from "react";

export const ScenePromo: React.FC<{ title: string; subtitle: string }> = ({ title, subtitle }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();

  const titleProgress = spring({ frame, fps, config: { damping: 12 } });
  const opacity = interpolate(frame, [0, 15], [0, 1], { extrapolateRight: "clamp" });
  const scale = interpolate(titleProgress, [0, 1], [0.85, 1]);

  return (
    <AbsoluteFill style={{ backgroundColor: "#070a13", justifyContent: "center", alignItems: "center" }}>
      <div style={{ opacity, transform: `scale(${scale})`, textAlign: "center", fontFamily: "sans-serif" }}>
        <h1 style={{ color: "#38bdf8", fontSize: 72, fontWeight: 800, marginBottom: 16 }}>
          {title}
        </h1>
        <p style={{ color: "#94a3b8", fontSize: 32, fontWeight: 500 }}>
          {subtitle}
        </p>
      </div>
    </AbsoluteFill>
  );
};
